# AlmostAGame

Protótipo 2D feito em Unity.

> ⚠️ **Este repositório tem apenas o build compilado (`2Dproject.exe` + `UnityCrashHandler64.exe`), sem o código-fonte do projeto Unity.** Se o projeto original (pasta `Assets/`, `ProjectSettings/`, etc.) ainda existir localmente, vale subir aqui — um repo só com o `.exe` não mostra nada do trabalho de verdade pra quem for avaliar o código.

## Como rodar (Windows)

Baixe `2Dproject.exe` e execute. Sem instalação.

## Stack

Unity (versão não registrada — adicionar ao recriar o projeto-fonte).

## Pendência

Adicionar o código-fonte do projeto Unity, ou — se o fonte foi perdido — deixar isso documentado aqui mesmo para não parecer upload incompleto.
